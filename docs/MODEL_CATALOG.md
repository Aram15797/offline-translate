# Каталог и установка офлайн-моделей

## Что работает

При открытии раздела «Офлайн-модели» приложение автоматически получает каталог по HTTPS, если адрес настроен в `app/src/main/assets/model-catalog-url.txt`. Кнопка «Обновить список моделей» повторяет запрос. Пользователь нажимает «Установить» у нужного пакета; ручное скачивание ZIP и импорт каталога ему не нужны. Импорт через системный выбор файла сохранён как дополнительный способ. Приложение проверяет RSA SHA-256 подпись, схему, срок действия и монотонное увеличение ревизии. Отсутствие CDN не мешает разработке установки: транспорт получает HTTPS-адреса пакетов из проверенного каталога.

Архив загружается через WorkManager с уникальной задачей на пакет, ограничением безлимитной сети по выбору пользователя и foreground-уведомлением. Файл `.part` сохраняется при потере сети, паузе и остановке процесса. Возобновление использует HTTP Range; ответ 200 вместо 206 начинает загрузку заново. Полный файл проверяется по SHA-256 до распаковки.

Пакеты хранятся в `files/models/packages`. ZIP распаковывается в отдельный временный каталог. Запрещены выход за границы каталога, абсолютные пути, Windows-пути, повторные пути и служебный путь `.verified`. Размер распаковки ограничен подписанным значением; лимит числа записей — 10 000. Установка завершается атомарным переносом каталога. При сбое временная распаковка удаляется. Удаление пакета отменяет его задачи и очищает все версии и частичные загрузки этого ID.

Установленные файлы ещё не означают работающий движок: ONNX/CTranslate2-инференс не подключён. Текстовый перевод продолжает использовать локальный разговорник.

## Формат

Подписываются точные UTF-8 байты JSON payload, а не повторно сериализованный объект. Envelope:

```json
{
  "keyId": "development-v1",
  "payload": "BASE64_UTF8_PAYLOAD",
  "signature": "BASE64_RSA_SHA256_SIGNATURE"
}
```

Payload:

```json
{
  "schemaVersion": 1,
  "revision": 2,
  "expiresAtEpochSeconds": 2100000000,
  "packages": [
    {
      "id": "mt-hy-ru-en",
      "version": "1.0",
      "name": "Armenian / Russian / English",
      "kind": "Translation",
      "languages": ["hy", "ru", "en"],
      "url": "https://YOUR_CDN/model.zip",
      "archiveBytes": 123456,
      "unpackedBytes": 234567,
      "sha256": "REPLACE_WITH_64_LOWERCASE_HEX_DIGITS"
    }
  ]
}
```

Это пример структуры, не готовый пакет. Размеры и хеш должны соответствовать реальному ZIP. `unpackedBytes` — сумма байтов всех распакованных файлов, без каталогов. Максимум — 20 ГиБ для архива и 40 ГиБ для распакованных данных. До скачивания проверяется место под оставшийся архив, распаковку и резерв 64 МиБ.

Поддержанные `kind`: `Translation`, `SpeechRecognition`, `SpeechSynthesis`, `Ocr`, `Diarization`. ID содержит строчные латинские буквы, цифры и дефисы; версия состоит из одной–четырёх групп цифр через точку. URL допускает только HTTPS без userinfo и fragment, порт 443 или стандартный. Redirect разрешён только на такой же безопасный HTTPS-адрес. Доверие к пакету основано на подписанном каталоге и SHA-256; certificate pinning для будущего CDN пока не настроен.

## Подготовка каталога

Приложение включает подписанный пустой каталог ревизии 1 и отдельный development public key. Приватный ключ стартового каталога намеренно не сохраняется. Для разработки реальных пакетов нужно создать свою пару RSA-ключей, заменить публичный ключ и встроенный каталог, затем пересобрать приложение. Для релиза нужна отдельная управляемая пара ключей; приватный ключ не входит в репозиторий или APK.

Утилита использует установленный OpenSSL и существующий приватный ключ:

```sh
python3 scripts/sign_model_catalog.py \
  --private-key /secure/path/catalog-private.pem \
  --payload /path/to/payload.json \
  --output app/src/main/assets/model-catalog.json \
  --public-key-output app/src/main/assets/model-catalog-public.der \
  --key-id-output app/src/main/assets/model-catalog-key-id.txt \
  --key-id development-v1
```

Следующие каталоги для импорта подписываются тем же ключом, с большей ревизией, без изменения assets. Приложение не принимает публичные ключи из импортированного файла. Откат ревизии запрещён даже после истечения срока предыдущего каталога. При автоматическом обновлении идентичный сохранённому файл разрешён, если его подпись и срок действия по-прежнему действительны. Изменённый файл с той же ревизией отклоняется. Ошибка обновления не удаляет сохранённый каталог и установленные пакеты. После смены доверенного ключа старый сохранённый каталог будет отклонён; новый можно импортировать вручную.

## Проверки и ограничения

Автотесты проверяют подпись, повреждение payload, неизвестный ключ, срок действия, откат, некорректную схему, URL и размеры; установку, докачку, отказ от Range, неверный Content-Range, хеш, опасные ZIP-пути, ограничение распаковки, отмену и удаление версий.

`UNMETERED` означает безлимитную сеть по классификации Android, а не строго Wi-Fi. Пауза останавливает WorkManager-задачу; возобновление создаёт новую задачу с сохранённым файлом. Ошибки сети автоматически повторяются до трёх раз после первой попытки.

Длительные foreground workers зависят от системных квот Android; восстановление, уведомления и ограничения фоновой работы ещё нужно проверить на реальных устройствах. Основа реализации: [WorkManager long-running workers](https://developer.android.com/develop/background-work/background-tasks/persistent/how-to/long-running), [управление задачами](https://developer.android.com/develop/background-work/background-tasks/persistent/how-to/manage-work).

Пока отсутствуют опубликованный CDN с реальными пакетами, загрузка дельт, перенос на SD, профили качества, учёт RAM, повторная проверка каждого установленного файла на повреждение и подключение инференса. Следующий шаг — выбор настоящей модели для армянского и привязка её формата к runtime.

## Как получить установку одной кнопкой

Работу разработчика нужно выполнить один раз перед публикацией:

1. Выбрать и проверить runtime на Android и формат модели. Например, файл Whisper для whisper.cpp требует JNI-интеграции whisper.cpp, а Marian/OPUS-MT — совместимого движка, весов и токенизатора. Произвольный файл PyTorch нельзя объявлять готовым Android-пакетом.
2. Подготовить ZIP со всеми файлами конкретной модели и необходимыми лицензиями. Для перевода через промежуточный язык можно включить обе модели в один пакет `Translation`, но runtime должен знать структуру и выполнять оба шага. Для речи ASR, перевод и TTS остаются отдельными компонентами, пока не реализована схема зависимостей. Одна кнопка здесь устанавливает один ZIP, а не автоматически все три типа моделей.
3. Опубликовать ZIP по стабильному HTTPS-адресу на своём CDN или хранилище с поддержкой HTTP Range. Не использовать адреса страницы модели вместо адресов файлов.
4. В payload указать точные `archiveBytes`, `unpackedBytes` и SHA-256 ZIP. Подписать каталог существующей утилитой `scripts/sign_model_catalog.py`; публичный ключ и начальный каталог включить в APK. Для обновлений сохранять ключ и увеличивать ревизию. Приватный ключ хранить отдельно от сервера скачивания.
5. Опубликовать подписанный envelope, например `https://models.example.org/catalog.json`, и записать его адрес в `app/src/main/assets/model-catalog-url.txt` перед сборкой. Файл сейчас пуст: фиктивного сервера в приложении нет. Адрес не содержит секретов и не связан с `OPENAI_API_KEY` или `.env` облачного gateway.
6. Проверить на устройстве установку, потерю сети, докачку, нехватку места, удаление и фактический перевод установленным runtime. Только после этого объявлять пакет доступным для пользователей.

Для пользователя остаётся: открыть «Модели» → выбрать нужный пакет → нажать «Установить». Каталог загружается при открытии раздела, сами большие файлы — только по нажатию. Если включено ограничение безлимитной сети, установка может ожидать подходящей сети. Без интернета сохраняется последний проверенный каталог в пределах его срока действия.

Текущая реализация готовит канал доставки, но не публикует чужие веса, не подтверждает права на распространение и не подключает инференс автоматически. Статус «Файлы установлены» намеренно не означает «Офлайн-перевод работает».

### Подготовка ZIP без ручного подсчёта размеров

Утилита требует Python 3.9+ и уже подготовленный каталог совместимой модели. Она не конвертирует веса и не проверяет качество перевода:

```sh
python3 scripts/prepare_model_package.py \
  --source /path/to/android-compatible-whisper \
  --output /path/to/releases/asr-small-1.0.zip \
  --id asr-small \
  --version 1.0 \
  --name 'Распознавание речи · Small' \
  --kind SpeechRecognition \
  --languages hy ru en \
  --url https://models.example.org/asr-small-1.0.zip \
  > /path/to/releases/asr-small-entry.json
```

На выходе — ZIP и JSON-запись с точными размерами и SHA-256. Вставьте объект из JSON в массив `packages` payload и подпишите каталог. Утилита запрещает символьные ссылки, служебный `.verified`, опасные пути, пустой пакет, вывод внутрь исходного каталога и перезапись существующего ZIP. Весам желательно дать версионный неизменяемый URL; новая версия — новый ZIP и хеш.

Проверка утилиты:

```sh
python3 -m unittest discover -s scripts/tests -v
```
