# Подключение облака Lingua Voice

Backend находится в `backend/`. Android обращается только к нему; `OPENAI_API_KEY` не добавляется в APK, Gradle, ресурсы или настройки телефона. По умолчанию приложение остаётся в режиме «Только офлайн».

## Запуск

1. Скопировать `backend/.env.example` в `backend/.env`.
2. Заполнить `OPENAI_API_KEY` ключом серверного проекта. Установить лимиты расходов в кабинете провайдера.
3. Заполнить `LINGUA_ACCESS_TOKEN` отдельным случайным токеном для подключения приложения. Не использовать здесь ключ OpenAI. Токен можно создать командой `python3 -c 'import secrets; print(secrets.token_urlsafe(32))'`.
4. Собрать и запустить контейнер:

```sh
docker build -t lingua-gateway backend
docker run --rm --env-file backend/.env -p 127.0.0.1:8080:8080 lingua-gateway
```

5. Опубликовать gateway за HTTPS reverse proxy с валидным сертификатом. Ограничить размер тела запроса 12 МБ, количество соединений и частоту запросов на уровне reverse proxy. Настройки DNS, TLS и домен зависят от вашего хостинга. Android-клиент намеренно не допускает HTTP, URL с паролем, параметрами и фрагментами и не следует перенаправлениям.
6. В приложении открыть «Настройки → Облачный сервис», указать HTTPS-адрес и `LINGUA_ACCESS_TOKEN`, выключить «Только офлайн», дать согласие и сохранить подключение.
7. «Проверить соединение» проверяет версию gateway и его авторизацию, без отправки текста и без платного запроса к провайдеру. Этот тест не подтверждает действительность ключа OpenAI, доступность моделей или наличие средств. Для живой проверки затем перевести короткую произвольную фразу.

Без обоих серверных секретов `/v1/status` и рабочие методы возвращают `503 not_configured`; тестовые переводы не подставляются. `/health` — только проверка того, что процесс запущен.

## API

Все `/v1/*` требуют `Authorization: Bearer <LINGUA_ACCESS_TOKEN>`.

| Метод | Назначение | Вход |
| --- | --- | --- |
| `GET /v1/status` | Версия протокола и возможности | Без пользовательского текста |
| `POST /v1/translate` | Перевод hy / ru / en | `text`, `source` или автоопределение, `target` |
| `POST /v1/transcribe` | Распознавание записи | `audio` в base64, `mediaType`, необязательный `language` |
| `POST /v1/ocr` | Чтение текста изображения | `image` в base64, `mediaType` |
| `POST /v1/speech` | Синтетический голос | `text`, `language`, `speed`; ответ MP3 |
| `POST /v1/meetings` | Реплики с метками говорящих | Аудио как в `/v1/transcribe` |
| `POST /v1/summary` | Резюме и задачи из стенограммы | `text`, `target` |

Полная схема доступна в `/docs` запущенного gateway. Сервер принимает до 4000 символов перевода, до 8 МБ аудио и до 6 МБ изображения после декодирования. Android перед отправкой уменьшает фото до длинной стороны не более 2048 пикселей и учитывает EXIF-поворот. Запись фразы на телефоне ограничена 60 секундами; распознавание начинается после остановки. Это пакетная обработка, а не потоковые субтитры.

Модели задаются переменными окружения, значения по умолчанию перечислены в `.env.example`. Их доступность зависит от аккаунта провайдера. Качество армянского и реальные задержки требуют проверки на согласованном наборе примеров.

## Данные и доступ

- Отправка с телефона запрещена без согласия и при включённом режиме «Только офлайн».
- Известные фразы сначала переводятся локально; облако используется как fallback.
- Токен gateway сохраняется на телефоне в зашифрованном виде с ключом Android Keystore. Черновик токена не записывается в SavedState.
- Аудио, фото и MP3 используются как временные файлы в приватном кэше. Аудио и озвучивание очищаются после обработки; оставшиеся после завершения процесса файлы очищаются при следующем запуске. Для незавершённого захвата камеры предусмотрен отдельный файл с очисткой после обработки и удалением устаревшего файла.
- Отмена на телефоне закрывает его запрос, но уже принятый провайдером запрос может завершиться и учитываться в расходах.
- Backend не ведёт журнал тел запросов и не сохраняет пользовательские файлы. Запросы Responses отправляются с `store=false`. Это не является обещанием отсутствия хранения на стороне провайдера: применяются его собственные условия обработки данных.
- Общий bearer token и лимит 30 запросов в минуту предназначены для частного подключения и закрытой беты. Публичный релиз требует индивидуальной авторизации, Play Integrity, квот пользователей, мониторинга расходов, защищённой доставки конфигурации и проверки инфраструктуры. Текущий gateway не является готовой многопользовательской платёжной платформой.

## Проверки

```sh
python3 -m pip install -r backend/requirements-dev.txt
python3 -m pytest backend/tests -q
```

Тесты используют `httpx.MockTransport`; платные внешние запросы не выполняются. Они проверяют контракты и ошибки, но не качество настоящего перевода, OCR или речи. В некоторых ограниченных песочницах Starlette TestClient не может создать межпоточный портал; в таком случае набор нужно запускать в обычном локальном окружении.

Официальные источники реализации: [Structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Speech to text](https://developers.openai.com/api/docs/guides/speech-to-text), [Text to speech](https://developers.openai.com/api/docs/guides/text-to-speech), [Images and vision](https://developers.openai.com/api/docs/guides/images-vision).
